# Requisitos Funcionales

* **RF-01 Gestión de Plantillas Clínicas:** El sistema debe proveer los formatos estandarizados e independientes para hospitalización, hemodiálisis, consulta externa, quirófano y cuidados intensivos (neonatales, pediátricos y adultos), basandose de las indicaciones de la guia operativa de registros clínicos de enfermería 39 del ISSSTE y otras instituciones.
* **RF-02 Gestión MultiPaciente y Navegación:** El sistema debe permitir al profesional de enfermería gestionar simultáneamente la información de varios pacientes o camas, organizando el acceso mediante un sistema de pestañas.
* **RF-03 Accesibilidad Contextual a Escalas:** El sistema debe proporcionar acceso directo a las herramientas de valoración clínica exactamente en las secciones correspondientes de la hoja de enfermería.
* **RF-04 Controles de Selección Rápida:** El sistema debe limitar la entrada de texto libre en campos predefinidos, obligando al usuario a presionar botones o seleccionar opciones preconfiguradas para escalas clínicas (Glasgow, EVA, Flebitis Maddox, Downton, Bristol).
* **RF-05 Validación de Valores Clínicos:** El sistema debe incluir reglas de validación lógica de entrada de datos (alertas o límites numéricos) al capturar constantes vitales como presión arterial, temperatura, balances de líquidos y puntajes de escalas.
* **RF-06 Generación de Gráficas Automáticas:** El sistema debe trazar automáticamente las gráficas clínicas de signos vitales (temperatura, tensión arterial, etc.) basandonos a las instrucciones exigidas por la guía operativa 39 a partir de los datos ingresados.
* **RF-07 Generación e Impresión de Hojas de enfermería:** El sistema deberá imprimir de manera nativa las hojas de enfermería al darse la indicación de impresión en la misma interfaz por parte del enfermero.
* **RF-8 Impresión en Conjunto** El sistema deberá poder imprimir las hojas de enfermería en conjunto desde el inicio de las pestañas para indicar cuáles y cuántas hojas de enfermería se imprimirán para generar la cola de impresión y enviarla a la impresiora.
* **RF-9 Protocolo de Seguridad en Impresión** El sistema deberá emitir una advertencia al detectar varias secciones vacias o importantes en la(s) hoja(s) de enfermería al intentar imprimir para evitar un error y un desperdicio y señalar las partes en la misma advertencia.
* **RF-10 Gestión de Firma Digital:** El sistema debe permitir al enfermero adjuntar, guardar y administrar una firma hecha a mano desde la pantalla para poder gestionar en los apartados que requieran doble verificación en las hojas de enfermería.
* **RF-11 Inserción Rápida de Firma:** El sistema debe habilitar un botón de acción rápida que inserte automáticamente la firma del enfermero en los apartados de doble verificación de las hojas de enfermería.
* **RF-12 Transferencia Vía QR/Bluetooth (Lotes):** El sistema debe generar códigos QR para emparejar dispositivos y compartir expedientes de pacientes en lotes de 1 hasta 10 pacientes simultáneos mediante conexión Bluetooth local.
* **RF-13 Confirmación de Doble Factor en Transferencias:** El sistema debe requerir una confirmación de dos pasos entre el emisor y el receptor antes de ejecutar la transferencia vía QR/Bluetooth, garantizando que no haya pérdida de datos y de una manera breve para no entorpecer la velocidad.
* **RF-14 Transferencia P2P (Peer-to-Peer):** El sistema debe ejecutar el intercambio de expedientes entre enfermeros al cambiar de turno mediante protocolos de proximidad (Bluetooth Low Energy o Wi-Fi Direct), utilizando el código QR exclusivamente para establecer la vinculación segura entre los dos dispositivos físicos.
* **RF-15 Cálculo Automático de Fórmulas:** El sistema debe calcular automáticamente el Índice de Masa Corporal (IMC), Superficie Corporal, Presión Arterial Media y balances de control de líquidos (ingresos/egresos totales) en los apartados que lo requieran en las hojas de enfermería sin requerir cálculos mentales del usuario.
* **RF-16 Inserción Automatizada de Firma con Datos de Identificación:** El sistema debe permitir al usuario validar las secciones que requieren firma (incluyendo los apartados de doble verificación) presionando un único botón de acción en la interfaz gráfica. Al compilar y generar la hoja de enfermería, el sistema debe plasmar automáticamente la firma digital del enfermero en la hoja de enfermería.
* **RF-17 Detección de apartados únicos** El sistema deberá detectar aquellos apartados que se pintan de un color diferente al del turno del enfermero, para la impresión final se plasme del color correspondiente basado en las indicaciones de la Guía Operativa 39 (Registros Clínicos de Enfermería del ISSSTE) y otras guía de otras instituciones.
* **RF-18 Visualización de la hoja de enfermería** El sistema deberá contener un apartado para poder visualizar la hoja de enfermería que se encuentra en proceso de llenado para poder visualizar todo lo escrito durante el día y por los turnos.
* **RF-19 Borrado de hoja de 24 horas** El sistema deberá eliminar todas aquellas hojas de enfermería que se encuentren abiertas más de 10 horas extra del horario que tenga cada hoja de enfermería segun la institución, esto si no se ha realizado la impresión y la verificación de 2 pasos para finalizar la hoja de enfermería post-impresión.
